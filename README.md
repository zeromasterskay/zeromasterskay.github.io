# Зеро Мастерская

Лендинг веб-студии «Зеро Мастерская» (Самара). Студия делает лендинги, многостраничные сайты и интернет-магазины для малого бизнеса.

Сайт: https://zeromasterskay.github.io

## Что внутри

- Один файл `index.html`: HTML и CSS без фреймворков и сборки
- Адаптивная вёрстка под телефон, планшет и компьютер
- Светлая и тёмная тема, переключается по настройкам устройства
- Анимация куба отключается для тех, кто выбрал в системе «уменьшить движение»
- Шрифты Manrope и Unbounded с Google Fonts

## Запуск

Откройте `index.html` в браузере. Сборка и установка не нужны.

## Публикация

Загрузите `index.html` в корневую папку хостинга (`public_html` или `www`) и включите SSL.
